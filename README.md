# Projeto Flask Git


Projeto desenvolvido para a disciplina de **Desenvolvimento Web III**, com o objetivo de praticar o desenvolvimento de aplicações utilizando o framework Flask e o controle de versões com Git e GitHub.

Durante o desenvolvimento, foram implementadas diferentes funcionalidades estudadas em aula. As alterações do projeto foram registradas por meio de commits e branches no GitHub.

---

## Tecnologias utilizadas

- Python
- Flask
- HTML
- CSS
- Jinja2
- Git
- GitHub
- Visual Studio Code

---

## Etapas do Projeto

- Exercício 1 - Templates e páginas estáticas

Implementação inicial das páginas HTML utilizando o Flask.
Foram criadas páginas dentro da pasta templates e utilizada a função render_template() para renderizar os arquivos HTML.
Foram trabalhadas páginas estáticas, como página inicial e página de contato.

- Exercício 2 - Páginas dinâmicas

Implementação da passagem de informações do código Python para os arquivos HTML.
Foram utilizadas variáveis e dicionários como argumentos da função render_template(), permitindo que os dados fossem exibidos dinamicamente nas páginas.

- Exercício 3 - Parâmetros pela URL

Implementação de rotas dinâmicas.
Os valores passaram a ser recebidos diretamente pela URL e utilizados nas funções do Flask para modificar o conteúdo apresentado ao usuário.

- Exercício 4 - Herança de templates

Implementação da herança de templates utilizando Jinja2.
Foi criado um arquivo base para armazenar elementos comuns às páginas da aplicação.

- Exercício 5 - Arquivos estáticos e CSS

Implementação de arquivos estáticos na aplicação Flask.
Foram utilizados recursos como:
- arquivos CSS;
- imagens;
- pasta static;
- estilização das páginas;
- passagem de argumentos através das rotas.

- Exercício 6 - Método GET

Implementação da passagem de parâmetros utilizando o método HTTP GET.
As informações enviadas pela requisição passaram a ser recuperadas pela aplicação Flask e utilizadas no processamento das páginas.

- Exercício 7 - Método POST

Implementação da passagem de parâmetros utilizando o método HTTP POST.

# Branches

- main
Branch principal do projeto, contendo as primeiras versões e exercícios desenvolvidos.

- heranca-template
Branch criada para trabalhar a versão que utiliza herança de templates com Jinja2.

- metodos-http
Branch utilizada para continuar o desenvolvimento das funcionalidades relacionadas aos métodos HTTP, incluindo GET e POST.
